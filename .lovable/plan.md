
# خطة إعادة بناء Batshark 99 — نسخة احترافية متكاملة

الهدف: تحويل Batshark 99 من واجهة عامة إلى منصة عمل احترافية فاتحة الألوان، باسم واضح "بات شارك 99"، مع 3 مستويات لكل واحد منها مسار عمل حقيقي مختلف، ومولّد أسئلة ذكي وتفاعلي بدل النماذج المملة، وربط فعلي للباكند والذكاء الاصطناعي بمواقع العملاء.

---

## 1) الهوية البصرية الجديدة (فاتحة، احترافية، هادئة)

- استبدال الخلفيات الداكنة `slate-950` بنظام فاتح:
  - الخلفية الرئيسية: أبيض ناصع مع تدرّجات Off-white وLavender فاتح.
  - النصوص الأساسية: رمادي داكن `slate-900` بدل الأبيض.
  - الأكسنت: بنفسجي/سماوي خفيف Glassy، بدل النيون الفاقع.
- إعادة بناء `B99Layout.tsx` بثيم Light مستقل عن باقي الموقع (لا يتأثر بـ dark mode).
- صورة/شعار الهيرو الرئيسي يتم إعادة توليده بنسخة عصرية: تركيبة 3D هادئة، Glow ناعم، ظلال طويلة، بدون تأثيرات صارخة.
- عنوان المنصة في كل مكان: **بات شارك 99** (لا "بات شير 99").
- زر الدخول من داخل الموقع الرئيسي إلى Batshark 99 يصبح بطاقة بارزة بألوان الهوية الجديدة.

## 2) الواجهة الرئيسية الجديدة لـ /b99

تقسيم حديث ومرتب:

- شريط علوي ثابت: شعار + اسم "بات شارك 99" + أزرار (دخول داخلي / دخول خارجي).
- Hero فاتح: عنوان قوي + 3 أزرار رئيسية (ابدأ من Level 1 / لدي موقع / وظّف بات شارك).
- شريحة "كيف نساعدك؟" — 3 بطاقات للمستويات الثلاثة مع شرح مكثّف.
- شريحة "البوابات" — 4 بطاقات (Generator / Platform Builder / Ads Studio / Search).
- شريحة موثوقية + CTA نهائي.

## 3) المستويات الثلاثة (إعادة هيكلة كاملة)

### Level 1 — لا يملك شيئاً، أو لديه شيء غير احترافي
- مساران فرعيان داخل نفس الصفحة:
  - **بناء من الصفر**: نولّد له موقعاً كاملاً بالباكند والذكاء.
  - **عنده موقع غير احترافي**: نربط الباكند حقّنا بموقعه ونحسّنه.
- المخرجات: موقع منشور على `/p/:slug` + لوحة مالك + إعدادات الدفع/المنتجات.

### Level 2 — لديه موقع احترافي ويريد تعزيزه
- المالك يدخل صلاحيات موقعه (Domain, API key, نوع الباكند).
- يختار اشتراكه من ميزات إضافية:
  - تعزيز المحتوى والـ SEO
  - لوحة إحصائيات حية
  - مساعد ذكاء اصطناعي مدمج
  - مولّد إعلانات وفيديو
  - اقتراحات نمو دورية
  - محلل متقدم (CAC/LTV/Churn)
- صفحة "Integration Wizard" تشرح طريقة الربط (Snippet / Webhook / Zapier).

### Level 3 — يريد توظيف "بات شارك" كموظف رقمي
- نموذج توظيف: ما المهام؟ (تقارير، إيميلات، تحليل بيانات، متابعة موظفين، احتساب KPIs…)
- ربط مصادر البيانات الخاصة به (CSV / Sheets / API / موقعه).
- يختار قنوات الإشعار (إيميل / واتساب / داشبورد).
- النتيجة: "موظف بات شارك" يعمل في خلفية موقعه ويرسل تقارير دورية.

كل مستوى صفحة منفصلة فعلاً وليست نفس النموذج بألوان مختلفة.

## 4) مولّد الأسئلة التفاعلي (بدل النماذج المملة)

استبدال الـ Wizard الحالي بمحرك أسئلة ذكي:

- أسئلة على شكل بطاقات اختيار بصرية مع أيقونات وأمثلة.
- المحرك يقفز للأسئلة المناسبة بناءً على الإجابات السابقة (Branching).
- Progress bar أنيق + قدرة الرجوع/التعديل في أي وقت.
- بعد كل 2-3 أسئلة، يظهر "ملخّص حيّ" لما تم فهمه عن البزنس.
- زر "اقفز للنتائج" متاح للمستخدم المتقدم.
- اقتراحات إجابات من الذكاء (يكتب جزءاً → AI يكمل).

## 5) ربط الباكند والذكاء الاصطناعي بمواقع العملاء

- إنشاء Edge Function: `b99-bridge` تولّد:
  - `client_api_key` فريد لكل منصة/عميل.
  - `embed_snippet` (سكربت JS صغير يضاف لموقع العميل).
  - `webhook_url` لاستقبال أحداث من موقعه.
  - `ai_proxy_endpoint` لاستدعاء الذكاء بأمان.
- جدول جديد: `b99_integrations` يحفظ مفاتيح وحالة الربط لكل عميل.
- صفحة `/b99/integration/:platformId` تعرض كل الأكواد الجاهزة للنسخ.
- توثيق مرئي خطوة بخطوة (3 خطوات: انسخ → الصق → فعّل).

## 6) استوديو الإعلانات (Ads Studio) — ترقية

- استبيان أقصر وأكثر بصرية (5 خطوات بدلاً من 12).
- المخرج: Storyboard مرئي + سكربت + Voiceover + Prompt جاهز لمولّد فيديو + خطة نشر.
- معاينة فيديو متحركة Mock داخل الواجهة.

## 7) محرك البحث العلمي

- واجهة بحث مركزية (Google-like) بثيم فاتح.
- نتائج مصنّفة + إجابة مباشرة + اقتراحات عمل.
- يبحث داخل المنصات والحملات والمستندات.

## 8) قاعدة البيانات (Migrations)

- جدول جديد: `b99_integrations` (platform_id, client_api_key, snippet, status, level).
- جدول جديد: `b99_ai_employees` (level 3 — owner, tasks, channels, schedule).
- إضافة `level` إلى `generated_platforms` (1/2/3).
- RLS: المالك أو CEO فقط للقراءة/التحديث.

## 9) الأمان

- تعطيل endpoint تغيير كلمة مرور الرئيس بعد التأكد من إعدادها.
- مفاتيح API للعملاء مشفّرة وتُعرض مرة واحدة فقط.
- التحقق من ملكية المنصة قبل أي تعديل.
